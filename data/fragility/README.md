# 基准脆弱性曲线

`baseline_fragility.csv` 是在只有风光荷和拓扑资料时使用的工程先验，不是阿拉山口实测曲线。曲线采用 Logistic 形式：

`P(I) = Pmax / (1 + exp(-(I - median) / scale))`

其中 `exposure_probability` 是全年暴露期的上限概率；代码会用 `-ln(1-P)/8760` 转为小时故障强度，再由序贯状态模型抽样。不能把 `P(I)` 直接当成每小时重复故障概率。

参数按 base、conservative、optimistic 三个情景给出。`low` 可信度表示文献和工程先验，仅用于流程、区间和敏感性分析；阿拉山口数据到位后替换这些行的强度尺度、设备类型、修复时间和来源，不修改下游接口。

参考方向：风致输电塔线脆弱性分析，DOI `10.1109/icepg67373.2025.11466894`；风雨耦合失效演化，DOI `10.1016/j.engfailanal.2026.111149`；配电网风暴脆弱性建模，DOI `10.1049/cp.2017.0342`。这些文献支持曲线形式和强度分层思路，表中数值仍需在当地资料到位后校准。
