# 脆弱性参数：待核实的研究假设

本表的数值是分析者假设，未从论文正文或图表提取，也未经专家审定。此前将它们称为“文献基准”不准确。现有 DOI 仅通过书目检索获得，不能作为表内数值的出处。

当前程序将 Logistic 概率按配置 exposure_hours 换算成常强度率。只有当概率确实表示同一暴露时长内的累计失效概率，并接受常强度假设时，这一转换才有意义。8760 是旧演示假设，不是普适换算依据；事件峰值条件脆弱性不能直接解释为年度或逐小时概率。

当前只接入线路风灾情景；其他设备/灾害表项尚未统一接入。零故障试跑不代表模型校准成功，不应为了得到故障而任意放大概率。

只有风光荷功率及拓扑图时，不能唯一反推出风速、覆冰、降雨或故障统计。需要公开气象数据作为外部暴露输入，或者使用明确声明的灾害强度压力测试。拓扑图也未必含线路阻抗、热容量、长度等参数，这些需要单独假设并做敏感性分析。

后续须逐条补齐：原文/页码或图号、设备类型和电压等级、风速测量高度及平均时距、概率的时间定义、迁移理由、参数范围和修复时长来源。完成前不得将此表用于地区年度概率结论。
